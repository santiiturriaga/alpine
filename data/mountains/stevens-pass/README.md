# Stevens Pass geography

The playable grid follows the Front Side and Mill Valley slopes in Washington's central Cascades. Local metres use WGS 84 / UTM zone 10N (EPSG:32610) with origin 47.7441° N, 121.0920° W. X increases east, Z increases south, and elevation is in metres.

| Asset | Coverage and encoding |
| --- | --- |
| [terrain.bin](terrain.bin) | 521 × 431 samples at 10 m spacing over 5.2 × 4.3 km. Little-endian unsigned 16-bit elevations at 0.05 m quantization. |
| [backdrop.bin](backdrop.bin) | 561 × 721 samples at 80 m spacing over 44.8 × 57.6 km. Same elevation encoding. The wider southern extent includes Mount Stuart, Mount Daniel and Mount Hinman. |
| [forest.bin](forest.bin) | Unsigned 8-bit tree-cover fraction on the playable grid. 0 represents no ESA WorldCover class 10 in the cell and 255 represents full coverage. |
| [resort.json](resort.json) | Raster bounds and decoding parameters, 88 piste paths including 34 unnamed connectors, one learning-terrain area, 13 lift lines, 47 building footprints, 66 road or pedestrian-bridge segments, six parking polygons, and mapped landmark anchors. |

Rows run north to south and columns west to east. The first and last samples sit on the corresponding bounds, and elevation decodes as `offset + sample * scale`. The terrain grid samples 791–1,782 m. The backdrop spans 270–2,803 m. The forest mask averages 78% tree cover within the playable extent.

### Source data

- **Terrain.** Public-domain USGS 3D Elevation Program 1/3-arc-second seamless DEM, August 13, 2025 publication of [n48w122](https://prd-tnm.s3.amazonaws.com/StagedProducts/Elevation/13/TIFF/historical/n48w122/USGS_13_n48w122_20250813.tif) and [n48w121](https://prd-tnm.s3.amazonaws.com/StagedProducts/Elevation/13/TIFF/historical/n48w121/USGS_13_n48w121_20250813.tif). The playable raster uses native-resolution source windows. The backdrop uses a lower-resolution overview for each source tile. Both are reprojected and resampled to the local frame. [USGS 3DEP products](https://www.usgs.gov/3d-elevation-program/about-3dep-products-services)
- **Forest.** ESA WorldCover 10 m 2021 v200, tile `N45W123`. Tree-class pixels were converted to a binary raster and area-averaged during reprojection. © ESA WorldCover project 2021 / Contains modified Copernicus Sentinel data (2021) processed by the ESA WorldCover consortium. [Zanaga et al.](https://doi.org/10.5281/zenodo.7254221), [CC BY 4.0](https://creativecommons.org/licenses/by/4.0/)
- **Mapped features.** © OpenStreetMap contributors, [ODbL 1.0](https://opendatacommons.org/licenses/odbl/1-0/). Downhill geometry and lift lines were selected by exact ski-area membership from OpenSkiData's November 15, 2026 OSM snapshot, supplemented with named expert pistes the official map confirms. Buildings, parking, roads, the Clock Tower, explicit lift pylons and selected summits use OSM directly. The run records retain source IDs and localized features retain their OSM IDs. [OpenStreetMap attribution](https://www.openstreetmap.org/copyright), [OpenSkiData attribution](https://openskidata.org/#license--attribution), [OSM query used in the build](https://www.openstreetmap.org/api/0.6/map?bbox=-121.126,47.713,-121.053,47.75)
- **Resort details.** The winter trail map supplies the named lift rows, advertised vertical rises and riders per hour. The winter and base-area maps supply trail rating corrections, the position of the Clock Tower relative to the named lodges, and the interpretation of the two mapped strands of the base-area rope tow as one installation. The resort lists 1,125 skiable acres, a 4,061 ft base, a 5,845 ft summit and 52 named trails. [Winter trail map](https://www.stevenspass.com/-/aemasset/sitecore/stevens-pass/maps/winter-2024-2025/20241115_SV_winter-trail_map_001.pdf), [Base-area map](https://scene7.vailresorts.com/is/image/vailresorts/20241210_SV_winter-base_map_001?fit=constrain%2C1&hei=2200&resMode=sharp2&wid=3437), [Resort statistics](https://www.stevenspass.com/the-mountain/about-the-mountain/mountain-info.aspx)
- **Landmarks.** The two resort peaks and the named regional anchor points use OpenStreetMap and USGS map and GNIS references. Peak-label elevation is sampled from the game's grid, which can lower individual summit heights at 80 m spacing. [Stevens Pass quadrangle](https://prd-tnm.s3.amazonaws.com/StagedProducts/Maps/USTopo/Current/PDF/WA/WA_Stevens_Pass.pdf), [Mount Daniel quadrangle](https://prd-tnm.s3.amazonaws.com/StagedProducts/Maps/USTopo/PDF/WA/WA_Mount_Daniel_20140121_TM_geo.pdf), [Mount Stuart quadrangle](https://prd-tnm.s3.amazonaws.com/StagedProducts/Maps/USTopo/PDF/WA/WA_Mount_Stuart_20140107_TM_geo.pdf), [USGS GNIS](https://www.usgs.gov/tools/geographic-names-information-system-gnis)

### Survey limits

- The paths have 51 distinct nonempty display names. That count uses the mapped names, which can split an official trail into independently named segments. The official map is a schematic and some named trails have no verified centerline in this extract. Lines are oriented by real endpoint elevations. Flat and uphill stretches remain where the mapped geometry crosses rolling terrain.
- Lift `capacity` is seats per chair or one rider per surface carrier. `verticalFeet` and `ridersPerHour` are operator figures. `chairsPerHour` divides the published hourly passenger figure by chair capacity. Tagged OSM durations give a game speed estimate through the measured slant distance. Pylons have mapped X/Z coordinates where available. Cable heights, sag, grips, platform positions and snow clearances are rendered estimates. Double Diamond and Southern Cross represent the two named parts of the shared lift. [Stevens Pass lift operations](https://blog.stevenspass.com/stevens-pass-update-1-19-24/), [Brooks and Daisy construction](https://blog.stevenspass.com/summer-2019-construction-brooks-and-daisy-chairlifts/), [Skytrac lift roster](https://skytraclifts.com/a-skytrac-near-you/)
- Footprints preserve the mapped exterior outlines. Where OSM has no height the game estimates it. Tree coverage is a land-cover classification for 2021, so individual tree locations, seasonal changes, snow, and skiable corridor widths are game approximations. This package represents the game terrain. For on-mountain navigation, use the operator's current map and signage. [Stevens Pass maps](https://www.stevenspass.com/the-mountain/about-the-mountain/trail-maps.aspx)

### Regeneration

Install Python packages `numpy`, `pyproj`, `rasterio`, and `shapely` 2 with GEOS 3.11 or newer. Place `runs.geojson`, `lifts.geojson`, and `metadata.json` from [OpenSkiData's GeoJSON export](https://openskidata.org/#download) in `.cache/`. The builder filters the large line-delimited features without loading the worldwide network into memory.

Run `python tools/build_mountain_data.py` from the repository root. The builder reads [sources.json](sources.json), fetches the OSM query once to `.cache/stevens-area.osm`, and reads only the required windows from the listed GeoTIFFs. To build with cached inputs, place the GeoTIFFs under their listed filenames in `.cache/`. Use `--output <directory>` to build to a separate location and `--cache <directory>` to use another input cache. OSM updates can change the inventory on later downloads. The game consumes the checked-in assets offline.
