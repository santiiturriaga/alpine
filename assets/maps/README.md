# Resort map references

The game draws its interactive trail map from the same routes and elevations used for skiing. These PDFs preserve the original illustrations for comparison.

- [Whistler Blackcomb winter trail map, 2025/26](whistler-blackcomb-winter-2025-26.pdf). [Tourism Whistler source](https://cdn.whistler.com/s3/pdf/maps/whistler-blackcomb-trail-map-2025-26.pdf)
- [Whistler village and base areas, 2024/25](whistler-village-base-2024-25.pdf). [Resort source](https://www.whistlerblackcomb.com/-/aemasset/sitecore/whistler-blackcomb/maps/winter-2024-2025/20241120_WB_winter-base_map_001.pdf)
- [Stevens Pass winter trail map, 2024/25](stevens-pass/stevens-pass-winter-2024-25.pdf). [Resort source](https://www.stevenspass.com/-/aemasset/sitecore/stevens-pass/maps/winter-2024-2025/20241115_SV_winter-trail_map_001.pdf)

The maps and their artwork retain the original resorts’ and artists’ copyrights. Alpine Descent is an independent fan project.
