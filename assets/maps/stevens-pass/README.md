# Stevens Pass winter atlas

These plates reproduce the Front Side, Mill Valley and base area from page two of the [2024/25 official Stevens Pass trail map](https://www.stevenspass.com/-/aemasset/sitecore/stevens-pass/maps/winter-2024-2025/20241115_SV_winter-trail_map_001.pdf). Artwork and PDF retain the resort’s and artists’ copyrights. The viewer first fits the original aspect ratio and then loads detail tiles as you zoom.

The Front Side and Mill Valley position markers interpolate between lift stations matched to the original illustration. Near the boundary of a calibrated face the position is approximate. The overview and base plate preserve the printed artwork. The full local PDF is available from every view.
